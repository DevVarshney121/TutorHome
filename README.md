# TutorHome

TutorHome is a dynamic full-stack tutor platform where students can find tutors, explore subjects, and submit tutor requests.

## Tech Stack

- HTML
- CSS
- JavaScript
- Django
- MySQL

## Project Goal

Build a simple, clean and fully dynamic tutor platform with:

- Student registration and login
- Google login
- Student dashboard
- Tutor profiles
- Subject management
- Tutor request system
- Admin dashboard
- Dynamic tutor and subject management
- Dynamic website content management
